⏱️ 0–2 นาที

  • Hybrid Ingestion: Valve Official API (คนเล่นสด) + Steam Store (ราคาบาท) + SteamSpy (รีวิว)
  • Database: PostgreSQL (เก็บ Time-series Data)
  • Machine Learning: Scikit-Learn (Dual-Model RandomForest)
  • UI: Streamlit + Plotly + Minimal Remix Icons

3. Tab 2: ดีลและส่วนลด AI
⏱️ 3–5 นาที
"ไฮไลท์สำคัญที่สุดของ Machine Learning อยู่ในแท็บที่ 2 ครับ คือ AI Discount Radar ทำงานร่วมกันแบบ Dual-Model Machine Learning:

1. Model ที่ 1 (Classifier): ทำนาย 'จังหวะเวลา' (Timing) ➔ ดูว่าใน 7 วันนี้ มีโอกาสจะจัดโปรลดราคากี่ % (เช่น โอกาสลด 85%) โดยวิเคราะห์จากรอบความถี่และวันที่ไม่ได้ลดราคามานาน
2. Model ที่ 2 (Regressor): ทำนาย 'ราคาที่จะลดเหลือ' (Price Forecast) ➔ คาดการณ์ว่าถ้าจัดโปร ราคาจะลดเหลือเงินกี่บาท (เช่น จากราคา ฿1,799 คาดว่าจะลดเหลือ ฿899) โดยประเมินจากประวัติส่วนลดเดิมของเกมนั้น
3. Decision Recommendation Engine: รวมผลทั้งสองตัวเป็นคำแนะนำผู้ซื้อทันที:
  • ถ้าโอกาสลดสูง (≥ 70%) ➔ แนะนำ 'แนะนำให้รอก่อน (WAIT)' อย่าเพิ่งซื้อราคาเต็ม
  • ถ้าโอกาสลดปานกลาง (40–69%) ➔ แนะนำ 'จับตาดูราคา (WATCH)'
  • ถ้าโอกาสลดต่ำ (< 40%) ➔ แนะนำ 'ไม่ต้องรอ (โอกาสลดต่ำ)' ครับ"
สเปกทางเทคนิคของโมเดล (Dual-Model Architecture):
  • Algorithms: RandomForestClassifier + RandomForestRegressor
  • Key Features: ประวัติรอบการลดราคาในอดีต, ระดับราคาเดิม, วันที่ตั้งแต่ลดครั้งล่าสุด, ยอดผู้เล่น CCU
  • Database Table: steam_discount_predictions
จุดที่เอานิ้วชี้บนจอ:
  • ชี้ที่การ์ด 3 กล่องด้านบน: ป้ายสีส้ม 'แนะนำให้รอก่อน' และ ป้ายสีฟ้า 'จับตาดูราคา'
  • ชี้ที่ตัวเลขราคาคาดการณ์: ฿1,799 ➔ คาดว่าจะลดเหลือ ฿899 (-50%)
  • ชี้ชาร์ตเปรียบเทียบราคาเต็ม vs ราคาโปรโมชั่นสำหรับเกมที่ลดราคาอยู่จริง ณ วันนี้

6. รวมคำถามที่อาจารย์ชอบถาม (Q&A)
❓ Q1: ทำไมถึงเลือกใช้ Dual-Model (Classifier + Regressor) แทนที่จะใช้โมเดลเดียว?
💡 ตอบ: เพราะการลดราคาเป็น 2 ขั้นตอน (Two-stage Decision): ขั้นแรกคือ 'จะลดหรือไม่ลด' (Classification) และขั้นที่สองคือ 'ถ้าลด จะลดกี่ %' (Regression) การแยก 2 โมเดลช่วยแก้ปัญหา Zero-inflation ทำให้โมเดลที่สองแม่นยำขึ้นมากครับ
❓ Q2: ทำไมถึงเลือกใช้ RandomForest สำหรับงานนี้?
💡 ตอบ: เพราะพฤติกรรมการลดราคาและยอดผู้เล่นมีความสัมพันธ์แบบ Non-linear สูง RandomForest สามารถจับความสัมพันธ์ระหว่าง Features ได้ดีมากโดยไม่ต้อง Normalize ข้อมูลเยอะ และทนต่อ Outliers ครับ
❓ Q3: ถ้า API ของ Steam ล่ม Pipeline จะหยุดทำงานไหม?
💡 ตอบ: ไม่หยุดครับ ใน Airflow ได้ออกแบบให้มีระบบ Retry อัตโนมัติ 2 ครั้ง และมี Fallback ไปดึงข้อมูลจากแหล่งสำรอง ทำให้ Pipeline มีความทนทาน (Fault Tolerance) ครับ
